## 先看线路，再看配置

做代理用，服务器到你这边的线路很重要。同一台服务器，用家里宽带和用手机流量连，表现可能不一样。别只看几核 CPU、多大带宽，还要看机房在哪、每月多少流量、流量用完了怎么处理。

线路速度我没有系统地测过，所以没法保证买哪台一定快。能测的话，尽量用你以后常用的网络去测。

## 开通时选什么

系统选 **Ubuntu 24.04**，后面的部署步骤都是按它写的。服务器要有独立的公网 IPv4，能用 SSH 登录、能装软件。

三个节点默认用 TCP 443、2443、8443，HTTPS 管理页和订阅用 TCP 9443，CLIProxyAPI 用 TCP 9444。申请证书时的 HTTP 校验还要用到 TCP 80。UDP 应用能不能走代理，要按协议和客户端实际测过才知道，光看服务器有没有监听 UDP 说明不了问题。防火墙怎么放行，部署时会一步步设置。

域名现在不用买。教程里有直接给 IP 签证书的做法，有服务器 IP 就能往下走。

如果你的 VPS 上已经跑着网站或其他服务，先检查再动手。别为了跟着教程走，就直接把它重装了。

## 开通后，把这几样记下来

- **服务器 IP**：服务商后台一般能看到。
- **SSH 用户名和端口**：有的机器是 root 和 22，有的不是，照后台给的填。
- **登录方式**：初始密码，或者下载到电脑上的密钥文件。

这些信息存在自己电脑上就行。密码和私钥别传到仓库，也别贴进 Issue。

服务商给的是密码的话，可以先在自己的终端用密码登录，再配好密钥登录。确认另开一个终端也能用密钥连上以后，再关掉密码登录，免得把自己锁在外面。

准备好了，就去 [把服务器配起来](deployment.md)。
