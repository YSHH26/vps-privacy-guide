# 自动部署与干净系统复验

已确认需求见本机 handoff；本文件不保存真实目标或凭据。

1. 核实固定 S-UI 的 API、内置核心和客户端格式；并行实现面板配置、订阅/本机 HTML、模板与教程。
2. 实现本机目标核验、受限状态、指定目标的提供方 API 换系统与 SSH 重接、服务器分阶段安装。
3. 安装可信 IP 证书及续期同步，HTTPS 面板/订阅、独立 CLIProxyAPI，配置三种 TCP 节点。
4. 本机静态检查、固定核心解析；备份旧测试实例并保存加密副本。
5. 真正换系统测试 OS，从当前仓库上传明确清单的干净部署源；分层验收并修正入口。
6. 修正后重新装 OS、重新部署；本机 HTML 记录实测与未测项，保留私有完整证据。

部署入口默认不换系统；换系统命令绑定 SSH 别名、IP、VEID，并核验官方 API 映射。仅将源码清单上传，不上传 private/。S-UI 为节点事实来源；任何无法完成的真客户端或防泄露检查保留未测。
