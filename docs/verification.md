## 2. 服务检查

从本机执行 `python3 scripts/vps.py --state private/target.json verify`，再对照实际结果检查未自动覆盖的项目。

## 4. IP 防泄露

按 [详细方法](leak-protection.md) 执行，每个客户端分别记录：

- [ ] 指定代理与允许直连的范围已明确，私有保存本地公网地址作对照。
- [ ] TUN/VPN 路由覆盖预期应用；受保护 IPv4/IPv6 按预期代理或被阻断。
- [ ] DNS 没有意外回落到本地网络；WebRTC 没暴露本地公网 IP。
- [ ] 节点故障、客户端退出时，受保护流量不会自动直连。
- [ ] 切网、休眠唤醒、设备重启后重复上述检查。
